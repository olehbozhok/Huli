# Huli

**Huli** — штучна мова, яка зараз у розробці. Слово *huli* — це водночас її назва і привітання «привіт».

## Коротко про мову
- Порядок слів вільний, базовий — «хто — дія — що».
- Відмінків і закінчень немає: граматику передають окремі частки.
- Час: **ta** — минуле, **na** — звична дія, **lu** — майбутнє. Дієслово без частки означає дію саме зараз.
- **ni** — заперечення, **maa** — необов'язкова питальна частка в кінці речення.
- Множина — частка **urra** після іменника.
- Числівники взято з Esperanto: **unu**, **du**, **tri**, … **dek**, **cent**, **mil**.

## Приклади
| Huli | Переклад |
|------|----------|
| **Huli, tu naro voo?** | Привіт, як у тебе справи? |
| **Mi naro boma.** | Я почуваюся добре. |
| **Mi ta luma.** | Я говорив. |
| **Tu murr mi maa?** | Ти мене чуєш? |
| **Mi vidi lin urra.** | Я бачу людей. |
| **Sa ka ja ven boma.** | Ми добре говоримо й розуміємо. |
| **Doke!** | Дякую! |
